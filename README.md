# CDC DSA Assignments Repository

This repository contains all the **Data Structures and Algorithms (DSA)** assignments provided by the **Career Development Cell (CDC)** department of our college.  
The aim of this repository is to maintain a structured collection of all problems and their solutions for **practice, revision, and reference**.

---

## 📘 About
The **CDC Assignments** are designed to strengthen fundamental DSA concepts that are essential for:
- Coding interviews  
- Competitive programming  
- Problem-solving in software development  

This repository serves as a central place where all such assignments are organized topic-wise and can be easily accessed by students for self-learning.

---

## 🧠 Topics Covered
Assignments and solutions are categorized under the following key DSA topics:
- Arrays and Strings  
- Linked Lists  
- Stacks and Queues  
- Trees and Binary Search Trees  
- Graphs  
- Recursion and Backtracking  
- Sorting and Searching Algorithms  
- Dynamic Programming  
- Greedy Algorithms  
- Miscellaneous Problem Sets
